# AEGIS online edition — deployment candidate

This is a Streamlit interface using the original AEGIS calculation, chart and data-query engines. It is not a public exposure of the original localhost HTTP server. Each browser session gets a separate CloudWorkspace; no upload is stored in global shared caches. Files are processed in server memory. The hosting provider still processes uploaded data: do not upload confidential or personal records. Public-demo limits are 5 MiB, 25,000 rows, 500,000 cells, 8 custom charts. No model training, external AI call, local SQLite access or procurement occurs. The Qwen/Ollama mode and full local file connectors remain in the portable local edition. The Streamlit UI is a new adaptation, not pixel-identical or full feature parity. Community Cloud resource limits, hibernation, and deployment availability apply.

## Publish
1. Back up the existing repository and verify rights to publish the original/group-contributor code and data. Use GitHub Desktop to copy the contents of this folder to the existing AEGIS repo (or a separate deployment repo), commit and push. The ZIP is not itself the deployment artifact. Do not add raw restricted Olist data or secrets.
2. At https://share.streamlit.io/ sign in and choose Create app / existing app. Select `rabakshi55-stack/AEGIS`, the actual branch (e.g. `main`), entrypoint `streamlit_app.py`. Choose Python 3.12 in advanced settings. Choose an available custom subdomain such as `aegis-decision-intelligence`. Do not consider the proposed URL live until deployment succeeds.
3. Verify the logs, public app access, fictional sample, CSV and XLSX imports, chart builder, chart recommendation and Decision Copilot. Open two independent browser sessions and check that one cannot see the other's dataset. Test file removal and limits. Test mobile and desktop. Do not submit/publish as finalized until acceptance passes.
4. Optionally add the actual web URL to your GitHub README and LinkedIn. No Qwen credentials are required for this first online candidate. A separately hosted Qwen inference service with permission, secrets, privacy policy and quotas is necessary for online Qwen. Never expose users' local Ollama servers publicly.

Local smoke test: `python -m pip install -r requirements.txt`, `python -m streamlit run streamlit_app.py`. Run `python -m unittest discover -s cloud_tests -v` for core adapter tests. The Streamlit runtime was unavailable in the build environment; actual deployment and rendering must be tested on Streamlit. Python compile and adapter tests are not a full hosted acceptance test.
