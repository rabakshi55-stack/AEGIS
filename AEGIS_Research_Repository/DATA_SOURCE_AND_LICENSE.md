# Data origin and rights

- Primary historical source: Olist, *Brazilian E-Commerce Public Dataset by Olist*, Kaggle: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
- Published dataset license: CC BY-NC-SA 4.0 (non-commercial use, attribution and share-alike requirements).
- Original raw Olist files intentionally omitted from this GitHub-ready source package.
- Original Olist historical order registry reported in the AEGIS archive: 99,441 records. This is not the January 2018 benchmark size.
- `Research/Integrated_v02/` is generated **synthetic data** and must never be presented as Olist or real supplier data.
- Historical features and model outputs may be derived from Olist; review the CC BY-NC-SA conditions before redistribution.
- The user must authorize publication of code, notebook outputs, images and research data.
