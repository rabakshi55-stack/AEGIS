# AEGIS — Final reliability review (15 November 2026)

## Scope and version
Cumulative complete replacement of the audited edition plus the Analytical Relevance Update. Both editions share the updated cohort, chart, spreadsheet and hosted inference modules. Windows retains its private-runtime launcher, read-only SQLite intake and optional Ollama/Qwen. Online retains the existing Streamlit entrypoint and Groq GPT-OSS setup. No training, procurement, or research result modification was performed.

## Corrections from this review
- Chart descriptions now retain tied extrema, and a tied leader's share is stated per group. Shares of averages/medians are not presented as additive quantities. Derived scatter plots have source-recomputed Copilot context, including denominators and group names.
- Cohort comparisons compute average signed calendar-day delay over all valid actual/promised date pairs, and average positive delay over late records only. The full financial totals are independent of valid delivery dates. The combined question that explicitly asks for different financial and delivery eligibility routes to the checked comparison. Unspecified currency is still unspecified.
- Filtered chart requests that cannot be represented by the existing builder are rejected rather than replaced by an unfiltered or unrelated chart. Explicit requests for on-time rates, duration or lead-time relationships are not silently changed into late-rate charts. These alternative derived chart metrics are not implemented; the supported derived scatter uses quantity or purchase value versus late rate.
- Windows now creates and displays the supported derived scatter chart, with server-side recomputation, active dataset revision validation, group coverage hover details and chart-aware Copilot access. Its derived measures are not editable as raw-column charts; remove/recreate if needed. Hosted fallback on Windows can recommend a chart without calling an unavailable provider.
- Hosted Groq 429 responses set a process-wide bounded cooldown, honoring numeric Retry-After (fallback 60 seconds). The existing daily/minute request guard remains. The cooldown does not increase provider limits and is not a distributed usage counter. Standard analytics remain available.
- Spreadsheet intake rejects UTF-16/32 unsafe XML declarations, negative shared-string indices, duplicate cell references; public XLSX inspection is limited to 20 MiB expanded and 2,000 ZIP members, with invalid uploads leaving the previous dataset intact.
- Streamlit deployment version updated to avoid stale session objects; derived chart catalog labels are human-readable. The self-check now tests verified group-level scatter values and denominators as well as counts and ranking ties.

## Verification and known limits
The exact final offline suite results are recorded in FINAL_VERIFICATION.txt after extracting and testing the release archives. Tests include both existing suites and new independent cases. No real Groq request was made. Provider responses in automated checks are simulated. Streamlit was not installed in the test environment; an attempted installation could not find a distribution. Streamlit browser rendering, the live API, first-time Windows runtime setup and Windows browser rendering still require real-platform acceptance. The Python and JavaScript source are syntax-checked. These checks do not prove semantic correctness of every possible LLM query. Unsupported analytical scope, unusual data definitions, missing inputs, causal/forecast questions and other ambiguous requests may require clarification or manual verification. Standard analytics is a bounded engine, not an independent trained general language model. Live model quotas remain shared by public users. Real-world predictive reliability, supplier savings and operational certification remain unverified. No changes were made to protected research artifacts.

## Installation
Online: extract the complete archive; copy the contents of AEGIS_Research_Repository into the existing repository's AEGIS_Research_Repository directory. Keep .git in its parent intact; review and commit the changes, then push. Reboot the existing Streamlit app. Entry point AEGIS_Research_Repository/streamlit_app.py, Python 3.12, existing GROQ_API_KEY secret; do not commit the key. Research evidence > AEGIS reliability self-check > offline first, then optional live AI check with fictional data and consent. The local-only SQLite and Ollama options are intentionally not exposed on the public server.

Windows: extract into a fresh writable folder, open AEGIS, run CHECK_AEGIS.bat, then START_AEGIS.bat. First run may download verified private Python runtime from python.org; internet required. Optional local model: install Ollama, run SETUP_QWEN.bat. For hosted mode use START_AEGIS_AI.bat with your own Groq key (not distributed in the package). Keep the terminal open while using the browser application. Do not merge into an earlier installation because release integrity checks cover exact file bytes. No administrative rights or system Python installation intended.

## Release acceptance
The package is an academic research release candidate, not an enterprise-certified system. Report actual errors if they occur; do not weaken security or edit manifests just to make the checks pass. Test with non-sensitive fictional or authorized data only. The public repository must retain all applicable third-party licenses and accurate ownership disclosures.
